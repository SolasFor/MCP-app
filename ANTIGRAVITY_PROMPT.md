## 1. Доверие
Только официальный GitHub SolasFor/MCP-app, stable channel, строгие версии, no downgrade, без drafts/prereleases по умолчанию. HTTPS с проверкой сертификатов, allowlist конечных hosts/redirect, лимиты размера/таймаутов. Никаких произвольных URL из release body. Подписанный канонический manifest: schema/channel/version/commit/platform/format/asset name/size/SHA256/key_id. Detached Ed25519, встроенный trusted public key, ротация/отзыв ключей, fail-closed. Authenticode и доверенный издатель согласно утверждённой политике; без реального доверенного signing автоустановка заблокирована даже при включённой настройке. Не генерировать production private keys, не коммитить секреты, не доверять ключам из скачанного manifest. Тестовые ключи только в тестах. SHA256SUMS недостаточно. Первый переход с 1.0.2 — ручной доверенный bootstrap.

## 2. Загрузка и staging
Фоновая проверка с throttling, timeout/cancel, без зависания GUI. Auto-download opt-in. Защищённый staging, ACL, атомарная запись, потоковая проверка размера/hash, quota/free space. Отклонять ZIP traversal, absolute paths, symlink/reparse, duplicate/case collisions, zip bomb, неожиданные файлы. Повторная проверка подписи/asset непосредственно перед запуском; защита от подмены путей и гонок. Не запускать неподписанный код.

## 3. Установка и rollback
Отдельный helper вне заменяемого каталога, защищённый handoff, mutex и проверка PID identity/path/version. Auto-install opt-in, выключен по умолчанию и недоступен без доверенной подписи. Только явный Quit/согласованный restart, не tray. Проверить активные задачи/расписания/controlled processes, не трогать независимые процессы. Не заменять running EXE/_internal. Installed: штатный Inno Setup, проверенные аргументы и exit code, без автоматической эскалации, контракт rollback предыдущим проверенным пакетом. Portable: целостный directory swap, старый пакет до health confirmation. Если формат не поддерживается безопасно — явно BLOCKED, ручной вариант.
Устойчивое состояние транзакции при kill/power loss, disk full, access denied, installer failure, повторном запуске. Реальный startup + health/version/selftest, ограниченный timeout, rollback и диагностика без секретов. Не расширять BackupManager. Сохранить %APPDATA%, OAuth SQLite, токен владельца, DPAPI, scopes, SSH, tunnel profiles, workspaces, automation history; старые расписания N01 остаются paused до одобрения. Миграции обратно совместимы.

## 4. UI
Компактный PyQt6 по DESIGN.md, RU/EN, Dark/Light/System, DPI. Текущая/доступная версия, время проверки, changelog без опасного HTML, статус подписи, прогресс/отмена, настройки check/download/install и причина BLOCKED. Используй существующий блок обновлений, не добавляй лишних вкладок. Не активировать установку при открытии окна. Сохрани Safe/Allowlist/Full Access.
