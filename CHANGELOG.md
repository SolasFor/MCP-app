## [1.0.1] - 2026-11-26 (UX Polish, Context Menus, Gateway Onboarding, OAuth Redesign & Task Error Handling)
- **Cursor Audit & Read-Only Surface Cleanup (`app/ui/**`)**:
  - Removed ubiquitous `PointingHandCursor` from button factories, cards, tables, combos, toggles, sliders, nav items, and dialogs, leaving the pointer strictly on genuine hyperlinks (`#Link` / `#SubtleLink`), standard arrow cursors on UI controls, I-beam cursors on selectable/editable text, and splitters on resize handles. No global override cursor is used.
  - Removed misleading hover border feedback on read-only logs and non-editable inputs (`#CopyField`, `#Log`, read-only `QPlainTextEdit`).
- **Wheel-Safe Spinboxes (`app/ui/components/safe_spin.py`)**:
  - Added `SafeSpinBox` and `SafeDoubleSpinBox` ignoring mouse wheel events even when focused (while preserving up/down step buttons and arrow keys) and replaced all spinboxes across `ServersPage`, `DevicesPage`, `AutomationPage`, `SettingsPage`, `ProxyPage`, and `AddMcpServerWizard`.
- **AI Clients Table Alignment (`app/ui/pages/clients_page.py`, `app/ui/oauth_clients_dialog.py`, `app/ui/components/table.py`, `app/ui/theme.py`)**:
  - Added `TableCellCombo` + centered `QComboBox#TableCombo` QSS with font-metrics/DPI-aware row heights (`>= 38 px`) and column widths so inline access-scenario selectors stay vertically/horizontally centered without clipping across 100%–200% Windows scaling and RU/EN switches, while preserving wheel protection and instant live OAuth permission updates.
- **Unified Context Menus & Inactive Task Purge (`app/ui/components/context_menu.py`, `app/ui/pages/*`, `backend/tasks/{store,manager}.py`, `backend/process_runner.py`)**:
  - Added reusable Dark/Light RU/EN `AppContextMenu` + screen-clamped `⋯` row buttons and right-click menus bound specifically to the target row across `ClientsPage` (removing toolbar `revoke_button`, keeping confirmation), `TasksPage`, `GatewayPage`, `ServersPage`, `WorkspacesPage`, `DevicesPage`, `ExtensionsPage`, and `AutomationPage`.
  - Added transactional `TaskStore.delete_inactive_tasks` and `TaskManager.delete_inactive_task` / `purge_inactive_tasks` (7d / 30d / 90d / all inactive) strictly limited to terminal states (`succeeded`, `failed`, `cancelled`, `interrupted`), refusing active/cancelling/live tasks and cleaning only owned internal `spool`/`artifacts` directories while preserving user files and `mcp_execution_audit.jsonl`.
- **Automated MCP Gateway Onboarding (`backend/gateway/{templates,client_configs,discovery}.py`, `app/ui/gateway_add_wizard.py`, `app/ui/pages/gateway_page.py`)**:
  - Added guided 6-mode `AddMcpServerWizard`: 7-category verified template catalog, URL probe (`Streamable HTTP` + legacy `SSE`), upstream OAuth PKCE (`OAuthClientProvider` + encrypted `SecretStore`), JSON/file import, local AI-client auto-discovery (Claude Desktop/Code, Cursor, VS Code, Codex TOML with duplicate detection), and explicit STDIO runtime inspection without auto-execution; updated `discovery.py` metadata extraction for `mcp==2.3.0` (`server_info`/`protocol_version` with camelCase fallback).
- **Owner Token Flexibility & OAuth Consent Redesign (`app/core/token_store.py`, `app/core/service_manager.py`, `backend/oauth_provider.py`, `backend/server.py`)**:
  - Removed arbitrary length/charset/`strip()` constraints on owner secrets while keeping HTTP Bearer transport compatibility via separate encrypted `transport_bearer_token()` (`MCP_SECRET_TOKEN`) and exact UTF-8 consent form secret (`MCP_OWNER_SECRET_B64`), preserving leading/trailing spaces on paste.
  - Redesigned `/oauth/consent` and `/authorize` HTML pages with Dark/Light `prefers-color-scheme`, inline crisp SVG icons, RU/EN localization (`MCP_LANGUAGE` + `Accept-Language`), and prominent `full` access risk warnings.
- **Task Manager `task_start` Timeout Fix & Structured MCP Errors (`backend/tasks/errors.py`, `backend/tool_permissions.py`, `backend/server.py`)**:
  - Fixed `task_start` failing by default in `allowlist` (`timeout: int | None = None` now resolves dynamically to `15s` Windows / `12s` SSH in `allowlist`, `60s` in `full`, while still rejecting out-of-range explicit timeouts).
  - Wrapped all 8 `task_*` tools with structured `CallToolResult(is_error=True, structured_content=...)` responses across 13 `TASK_*` error codes, secret/path redaction, non-leaking `TASK_NOT_FOUND` on cross-client lookups, and `tasks.log`/`errors.log` diagnostics.
- **Windows ACL Hardening, Atomic I/O & Non-Destructive Startup Recovery (`app/platform/windows.py`, `app/core/{atomic_io,acl_recovery}.py`, `app/gui.py`, `main.py`, `app/selftest.py`, `packaging/{mcp_app.spec,build.ps1}`)**:
  - Added Win32 `FILE_ATTRIBUTE_REPARSE_POINT` detection (`is_reparse_point`) so `restrict_path_acl` refuses symlinks/junctions while applying protected `TokenUser`-SID DACLs without short `USERNAME` ambiguity or `Everyone` ACEs.
  - Added `atomic_io` (`atomic_write_bytes`/`atomic_write_text` with PID+TID temp names, `fsync`, transient Win32 sharing-violation retries, guaranteed `.tmp` cleanup on `ENOSPC`, and `try_init_private_dir`) across all config, secret, tunnel, and module stores.
  - Added bounded `diagnose_data_acls` and owner-confirmed `repair_data_acls` / `--repair-acl` (strictly scoped to `OWNER == TokenUser` SID, preserving DPAPI keys, encrypted vaults, `token.json`, and SQLite DBs), early GUI startup recovery prompt, `--selftest` ACL+SecretStore verification, explicit `pywin32` `hiddenimports`, and space-safe `-Python` path handling in `packaging/build.ps1`.
- **Persistent `MCP Owner Token` & Granular Per-Client Permissions (`app/core/{token_store,service_manager}.py`, `app/backend_entry.py`, `backend/{oauth_store,oauth_execution,oauth_provider,tool_registry}.py`, `backend/desktop/{models,manager}.py`, `app/ui/{oauth_execution_dialogs,main_window,pages/clients_page}.py`)**:
  - Added `TokenLoadStatus` / `TokenStorageError` so unreadable/locked `token.json` or DPAPI vaults never silently regenerate or overwrite an existing `MCP Owner Token` in GUI or `--headless` mode, blocking `preflight()` with actionable `--repair-acl` guidance and auto-recovering once readable.
  - Added per-client MCP tool policies (`exec_client_policies`: `denied_tools`, `allowed_tools_only`, keeping `OAuthStore.SCHEMA_VERSION == 3`), per-client Computer Use overrides (`DesktopPolicy.client_overrides`: `inherit`/`disabled`/`view`/`control`), RFC 6749 / CIMD URL `client_id` validation, cross-issuer default profile/allowlist synchronization without overwriting explicit client rules, `latest_persistent_resource_url` lookup, and `ClientPermissionsDialog` on `ClientsPage`.
- **Security Policy, Gateway Redirect Guard, Resource Cleanup, Tailscale Caching & Dialog Localization (`backend/security_policy.py`, `backend/gateway/{upstream_client,router}.py`, `backend/extensions/runtime.py`, `app/core/tunnels/tailscale.py`, `app/ui/components/silent_dialog.py`)**:
  - Fixed `workspace_path` NUL-byte check (`"\x00"`), NTFS alternate data streams (`:`), and Windows reserved device stems (`CON`, `PRN`, `AUX`, `NUL`, `COM1..9`, `LPT1..9`).
  - Added `httpx` redirect validation in `UpstreamClient` re-checking `validate_upstream_url` on `3xx` targets (blocking SSRF redirects to loopback/private/link-local/metadata IPs) and rejecting cross-origin redirects when upstream credentials/secret headers are configured.
  - Closed leaked pipes/reader threads on crashed extension worker restarts and `initialize` RPC timeouts, cached `tailscale status --json` (`30s` TTL) to avoid UI thread stalls, localized `SilentMessageBox` standard buttons (`RU`/`EN`), and isolated `APPDATA`/`LOCALAPPDATA`/`OAuthStore` in GUI and integration tests.
