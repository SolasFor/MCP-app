## Дополнение N03
Сохранить существующие backend registry/tools/schema и связи WorkspaceProfile.linked_servers. Без потери ID/ACL/secret refs; непривязанные профили доступны, unlink не останавливает и не удаляет сервер, workspace delete не уничтожает сервер и не расширяет неявно права при отвязке/удалении (`workspace_scoped`). Обеспечить единый авторитетный runtime (`LocalAdminClient` + cross-process runtime ledger с `ProcessIdentity`), единый порядок блокировок (`Workspace -> Server -> Automation -> Runtime -> RLock`) с bounded timeout, транзакционную согласованность (`SecretStore`/конфиги/`schedules.json`), fail-closed обработку пустых/потерянных/неизвестных конфигов, live-перепроверку прав перед каждым запуском процесса/перезапуском/задачей и полную интеграцию `workspace_run_task` с `TaskManager`. Удаление навигации только после функционального паритета, включая shortcuts/palette и старые page keys. Production gates N02 в docs/auto-update.md неизменны; N02 no-trust regression обязателен.

## Дополнение N04
Discovery только в выбранных границах через ленивый `os.scandir` с единым бюджетом записей/байт/времени/отмены по родителю и подпроектам monorepo (без полной материализации `iterdir`/`glob`), bounded read-only manifests, no process/network/install/secret read, no unsafe YAML, no reparse/traversal/TOCTOU, отказ от FIFO/специальных/устройств до открытия (`S_ISREG` + `O_NONBLOCK`). Python/Next.js/Node/Compose/monorepo/unknown, invalid/oversized manifests; точные предложения с provenance и ручной режим. Cancel/back без записи; explicit commit, duplicates/case aliases, stale plan (полная фиксация `proposal_fingerprint` и `plan_fingerprint` по командам, runtime/venv, Node path, параметрам серверов, связям и предупреждениям — как при первичном мастере, так и при переутверждении), atomic workspace+server links, rollback/fault injection. Единый согласованный контракт утверждения и переутверждения `SIGNIFICANT_MANIFEST_FILES` (изменение, удаление и появление значимых манифестов без сканирования всего исходного кода и без снятия защиты удалением `manifest_digests`) с атомарным обновлением Workspace и его исключительных `wizard_servers` через WAL-транзакцию `ManifestReapprovalDialog` → `commit_manifest_reapproval`, проверкой до и непосредственно перед dispatch (не затрагивая чужие/ручные/общие серверы и семантику Full Access). Новые Workspace read-only и без автоматического OAuth доступа (не путать пустой allowed_clients с deny-all), новые ServerProfile workspace_scoped/autostart=false, никакого запуска при создании. N03 runtime/tx/live auth и N02 production no-trust regression обязательны. RU/EN, themes, DPI, responsive UI.
