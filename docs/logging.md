# Постоянная система логирования MCP-app (`v1.0.0` Wave 2)

Централизованное постоянное хранение структурированных журналов для GUI (`app/gui.py`), бэкенда (`backend/server.py`, `app/backend_entry.py`) и расширений (`backend/extensions/runtime.py`).

## Расположение и файлы журналов

Основной каталог: `%APPDATA%\MCPApp\logs\` (переопределяется переменной окружения `MCP_LOGS_DIR` для дочерних процессов и тестов).

| Файл | Назначение |
|---|---|
| `app.log` | События GUI-приложения, переключение провайдеров, диагностика конфигурации |
| `backend.log` | Запуск и работа `MCPServer` / Starlette / Uvicorn |
| `tunnel.log` | Запуск, остановка и диагностика транспортных провайдеров (`Cloudflare Quick/Named`, `ngrok`, `Tailscale Funnel`) |
| `oauth.log` | События OAuth 2.1: DCR, `/authorize`, `/oauth/consent`, отклонения, смена прав клиентов и отзыв |
| `proxy.log` | Автопоиск прокси, handshake-проверки (SOCKS5/SOCKS5H/HTTP CONNECT) и маршрутизация туннеля |
| `computer_use.log` | Включение/автосохранение Computer Use и аварийная остановка |
| `gateway.log` | Инициализация и маршрутизация MCP Gateway |
| `tasks.log` | Очередь и выполнение фоновых задач (`TaskManager`) |
| `servers.log` | Управление локальными управляемыми серверами |
| `workspaces.log` | Операции с рабочими пространствами |
| `extensions.log` | Жизненный цикл и IPC дочерних процессов расширений |
| `ssh.log` | Удалённые SSH/SFTP подключения |
| `automation.log` | Планировщик, метрики и задачи автоматизации |
| `errors.log` | Автоматическое зеркало всех событий уровня `ERROR` и `CRITICAL` (без циклических записей) |
| `crash.log` | Необработанные исключения (`sys.excepthook`, `threading.excepthook`) и критические сбои |
| `archive/` | Сжатые `.log.gz` архивы ротированных журналов |

> **Защищённый аудит безопасности:** файлы `mcp_execution_audit.jsonl` и `desktop_policy_audit.jsonl` хранятся отдельно и **никогда не удаляются** при обычной ротации или нажатии «Очистить» во вкладке «Журналы».

## Настройки по умолчанию и управление

В разделе **Настройки → Постоянное логирование (%APPDATA%\MCPApp\logs\)** доступны:
- Включение/выключение записи на диск (по умолчанию: **включено**).
- Уровень логирования: `DEBUG`, `INFO` (по умолчанию), `WARNING`, `ERROR`, `CRITICAL`.
- Максимальный размер файла: `10 МБ` (диапазон `1–512 МБ`).
- Срок хранения архивов: `30 дней` (`1–3650 дней`).
- Общий лимит каталога: `200 МБ` (`10–10240 МБ`).
- Автоматическая ротация (`auto_rotate = True`) и архивация в `.gz` (`archive_enabled = True`).

## Безопасность, многопроцессность и экспорт диагностики

- **Редактирование секретов (`SecretRedactor`)**: выполняется **до** записи на диск, показа в UI и упаковки в диагностический архив — **даже на уровне `DEBUG`**. Скрываются `Authorization`/`Proxy-Authorization`, `MCP_SECRET_TOKEN`, `TUNNEL_TOKEN`, `CLOUDFLARE_API_TOKEN`, `NGROK_AUTHTOKEN`, `code`, `code_verifier`, cookies, пароли в URL и base64-скриншоты.
- **Межпроцессная блокировка**: GUI и `--backend` координируют запись и `.gz`-ротацию через файл-блокировку `.write.lock` с закрытием файловых дескрипторов до снятия блокировки (защита от `WinError 32` в Windows).
- **Диагностический ZIP («Экспорт диагностики…»)**: содержит только отредактированные журналы, версии ПО/агентов, обезличенные настройки/состояние прокси/OAuth-ошибки и состояние транспорта; **никогда** не включает секреты, базы OAuth (`*.sqlite3`), ключи `SecretStore`, пользовательские документы и скриншоты.
