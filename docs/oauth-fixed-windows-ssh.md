# Три сценария Windows и SSH через OAuth

MCP-app применяет **один глобальный сценарий ко всем подтверждённым OAuth-клиентам**.
Переключается на вкладке **«Главная» → «Сценарий доступа»**, сразу
применяется к запросам и не требует перезапуска сервера.

| Сценарий | Инструменты | Что может выполнить клиент |
|---|---|---|
| **Безопасный** | Только `server_info` | Никаких Windows или SSH-команд |
| **Белый список** | `server_info`, `oauth_windows_command`, `oauth_ssh_command` | Только точные команды и SSH-хосты, разрешённые владельцем |
| **Полный доступ** | Те же 3 инструмента | Произвольные команды в Windows и на SSH-хостах, при наличии доверенного ключа SSH |

## Важно: нет подтверждения каждого запуска

После выбора **Белого списка** или **Полного доступа** команды выполняются
по первому вызову AI-клиента. `approval_id`, очередь подтверждений и
дополнительные модальные окна для каждого действия больше не используются.

При выборе **Полного доступа** приложение отдельно предупредит об опасности
и потребует явного согласия **один раз при переключении режима**.
Это не ограничивает дальнейшие вызовы: каждый подключённый и подтверждённый
OAuth-клиент получит полномочия выбранного сценария.

## Настройка белого списка

1. На «Главной» запустите сервер и дождитесь публичного MCP-адреса.
2. Выберите «Белый список».
3. Нажмите «Настроить белый список Windows / SSH…».
4. Для Windows внесите по одной строке:

```text
whoami
ipconfig
systeminfo
pwd
ls
dir
echo
```

Такой набор предзаполнен при первой установке. Также можно добавить точную
команду `hostname.exe`. Вызов `whoami` будет выполнен сразу, а
`whoami /priv` — отвергнут, если строка `whoami /priv` не разрешена.

`dir`, `ls`, `pwd` и `echo` обрабатываются без Windows shell; `dir`
и `ls` показывают имена файлов в рабочем каталоге сервера.
`echo пример` выводит текст буквально, без обработки shell-операторов.

Для SSH дополнительно требуется задать **точные имена хостов**
и **точные команды** (например, хост `server.local`, команда `uptime`).
Внешние серверы доступны только с доверенными SSH host keys:
Paramiko использует `RejectPolicy`. При новом хосте проверьте его ключ
вручную и запишите в `known_hosts`.

В белом списке **нет масок команд** и нет общего разрешения на все
аргументы выбранного исполняемого файла. Не добавляйте интерпретаторы
или команды, через которые можно запускать произвольный код, если не
принимаете этот риск.

## Полный доступ

Windows-команды выполняются через `cmd.exe`, включая конвейеры и
перенаправления. SSH-команды выполняются через удалённый SSH shell.
Никаких дополнительных подтверждений нет. Запуск ограничен лимитом
времени, но **это не песочница Windows** и не защита от всех
вредоносных действий или дочерних процессов.

**Включайте только для полностью доверенных OAuth-клиентов** и лучше
под учётной записью Windows / SSH с минимальными необходимыми правами.

## OAuth и ссылки

При поддержке OAuth в MCP-клиенте достаточно адреса
`https://<текущий-адрес>.trycloudflare.com/mcp`. Секрет владельца
вводится только на странице подтверждения соединения MCP-app на
проверенном HTTPS-домене. `?token=...` отключён, даже если настройка
была включена в старой версии. Для ручной авторизации используйте
`Authorization: Bearer ...`.

OAuth scope `mcp:read` здесь используется как совместимый базовый
scope; **он не означает, что выбранный Полный доступ безопасен или
только для чтения**. Фактические возможности дополнительно определяет
глобальная политика в SQLite. Смена сценария действует на уже выданные
OAuth-токены.

На новом случайном домене Quick Tunnel набор разрешений сбрасывается
к «Безопасному». Для стабильного сценария и авторизации используйте
постоянный домен. После отзыва OAuth-клиента его токены перестают работать.

## «context canceled» в Cloudflare

Запись `failed to proxy HTTP: context canceled` сама по себе означает
прерванный запрос, а не гарантированный отказ туннеля. Проверяйте
локальный и публичный `/health` через «Главная →
Проверить MCP, OAuth и Cloudflare…». Время ожидания одобрения больше
не удерживает HTTP-запрос открытым, потому что одобрение не требуется.
