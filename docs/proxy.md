# Система прокси MCP-app (`v1.0.0` Wave 2)

## Три режима работы (`%APPDATA%\MCPApp\proxy.json`)

1. **`none` («Выключен — прямое соединение», по умолчанию для новых установок)**:
   - Прокси отключён; фиктивный адрес `127.0.0.1:1080` больше не подставляется автоматически.
   - Устаревшие отключённые конфигурации с неработающим `socks5://127.0.0.1:1080` безопасно мигрируют в `none`.
2. **`auto` («Автопоиск системного / локального прокси»)**:
   - Проверяет переменные окружения (`HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY` с учётом `NO_PROXY`), системный прокси Windows (`WinINET` в реестре HKCU и `netsh winhttp show proxy`), PAC-URL (анализирует статически и предупреждает при необходимости JS PAC-выполнения) и ограниченный список локальных VPN/прокси-портов на `127.0.0.1` (`10808/10809`, `2080/2081`, `7890/7891`, `12334`, `1080`, `8080`, `3128`, `8118`).
   - Каждый кандидат проходит **реальный handshake + подключение к целевому хосту + TLS-проверку** (`verify_proxy_candidate()`), а не только проверку открытого TCP-порта.
   - При сбое прокси трафик **никогда не сбрасывается молча на прямой выход (`direct`)** — вместо этого фиксируется явная ошибка в `proxy.log` / `tunnel.log` и UI.
3. **`manual` («Ручная настройка»)**:
   - Выбор протокола: `SOCKS5H` (DNS через прокси), `SOCKS5` (локальный DNS) и `HTTP CONNECT`.
   - Поля `Host`, `Port`, `Username` и `Password` (пароль хранится зашифрованным в Windows DPAPI `SecretStore` и не записывается открытым текстом в `proxy.json`).

## Особенности по транспортным провайдерам

- **Cloudflare Quick / Named**: использует локальный edge-relay мост (`app/core/edge_relay.py`) и прокси для `api.cloudflare.com:443`, `api.trycloudflare.com:443`, `region*.v2.argotunnel.com:7844`.
- **ngrok Agent v3**: CLI `ngrok` поддерживает только `HTTP_PROXY` / `HTTPS_PROXY` (`http://`). Если выбран `SOCKS5` / `SOCKS5H`, приложение честно предупреждает о несовместимости и не передаёт сломанную переменную окружения.
- **Tailscale Funnel**: управляется системным демоном Tailscale напрямую и не маршрутизируется через локальный прокси-мост MCP-app.

## Фоновая диагностика

Кнопка **«Диагностика»** на вкладке «Подключения → Прокси» в фоновых потоках проверяет прямое соединение и соединение через прокси для `api.trycloudflare.com:443`, `region1/2.v2.argotunnel.com:7844`, `api.cloudflare.com:443` и пользовательских хостов, отображая статус DNS, TCP, аутентификации (407 / SOCKS5 auth), TLS и задержку в мс.
