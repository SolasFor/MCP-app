# MCP app v0.8.2 — первый официальный Windows-релиз

MCP app — Windows-приложение для публикации собственного MCP-сервера через Cloudflare Tunnel и подключения AI-клиентов с OAuth 2.1.

## Возможности

- Объединённая «Главная» для запуска сервера, управления туннелем, OAuth и диагностики.
- OAuth 2.1 с PKCE и сохранением клиентов/токенов в защищённой SQLite-базе (ключ шифрования защищён Windows DPAPI).
- Отдельный сценарий для каждого OAuth-клиента: **Безопасный**, **Белый список** или **Полный доступ**; права изменяются из колонки «Права» без переподключения.
- **Базовый Windows-белый список для новых установок:** `ls`, `pwd`, `dir`, `echo`, `whoami`, `ipconfig`, `systeminfo`. Выбор режима по умолчанию остаётся **Безопасным** — команды запрещены, пока пользователь явно не разрешит их клиенту.
- В окне настройки белого списка добавлена кнопка **«Восстановить базовые команды»**. Ранее изменённые списки не расширяются автоматически.
- Выполнение разрешённых Windows- и SSH-команд без подтверждения каждого вызова. Для SSH по-прежнему проверяются ключи хостов.
- Диагностика локального сервера, публичного HTTPS, OAuth и MCP.
- Установщик и portable ZIP для Windows.

## Файлы

- **MCPApp-Setup-0.8.2.exe** — установщик для Windows 10/11 x64.
- **MCPApp-0.8.2-portable.zip** — portable-версия.
- **SHA256SUMS.txt** — контрольные суммы SHA-256 для проверки файлов.

## Безопасность и ограничения

**Внимание: режим «Полный доступ» позволяет авторизованному OAuth-клиенту выполнять произвольные Windows/SSH-команды от имени текущего пользователя, без подтверждения каждого запуска. Это не песочница и не безопасно для недоверенных клиентов.** Используйте «Безопасный» или ограниченный белый список, особенно при доступе из интернета.

OAuth-клиентам не нужен токен в ссылке `?token=`. Для подключения используйте HTTPS-адрес `/mcp`. Временный Cloudflare Quick Tunnel меняет адрес при новом запуске, что может потребовать повторной OAuth-авторизации.

**Файлы сборки не подписаны сертификатом издателя MCP app (Authenticode).** Windows SmartScreen может показать предупреждение о неизвестном издателе; контрольные суммы позволяют обнаружить изменения файлов, но не заменяют проверяемую цифровую подпись.

Сохраните копию `%APPDATA%\MCPApp` перед обновлением. Установщик сохраняет пользовательские настройки при переустановке, но резервная копия рекомендуется.

## Исходники и тесты

Релиз создан из `main` после успешного прогона unit/integration-тестов на Windows и Ubuntu. Собранный `MCPApp.exe` проходит `--selftest`; опубликованы SHA-256 контрольные суммы. Настоящие SSH-подключения к личным серверам и эксплуатация с реальными AI-клиентами требуют отдельной пользовательской проверки.
