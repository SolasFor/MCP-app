# MCP app v0.8.3 — исправления OAuth-логов и аудит Windows/SSH

Обновление официального Windows-приложения MCP app с Cloudflare Tunnel, OAuth 2.1 и выбором режима Windows/SSH для каждого OAuth-клиента.

## Что исправлено

- **Ложные ошибки OAuth-токенов:** успешные запросы к MCP `200/202` больше не сопровождаются предупреждением «Неверный токен в заголовке». Bearer-токены сторонних клиентов проверяет MCP SDK; ошибки фиксируются после фактического ответа `401/403`.
- **Сообщения запуска:** удалены устаревшие утверждения `read-only` и `execution tools: disabled` при OAuth. Отображаются действующие настройки, глобальный режим по умолчанию, число зарегистрированных клиентов, размер списков разрешений и путь аудита.
- **Cloudflare:** `context canceled` трактуется как отменённый HTTP/SSE-запрос, а не автоматически как сбой туннеля. Ошибки подключения к локальному MCP-серверу выводятся отдельно с адресом /health. Исходные строки cloudflared сохраняются.
- **Локальный журнал выполнений:** `%APPDATA%\MCPApp\server\mcp_execution_audit.jsonl` содержит время, идентификатор OAuth-клиента, его сценарий, тип Windows/SSH, результат, длительность и код завершения. Команды, их аргументы, stdout/stderr, токены, SSH-имена пользователей и хосты не записываются открытым текстом. Для сопоставления сохраняются SHA-256 отпечатки, файл автоматически ротируется.
- **Windows:** добавлено корректное освобождение дескрипторов нового журнала при самопроверке собранного EXE.

## Файлы Windows 10/11

- `MCPApp-Setup-0.8.3.exe` — установщик;
- `MCPApp-0.8.3-portable.zip` — переносная версия;
- `SHA256SUMS.txt` — SHA-256 двух опубликованных файлов.

Перед обновлением сохраните копию папки `%APPDATA%\MCPApp`. Настройки OAuth и профили клиентов не изменяются. Переподключение OAuth для этого обновления не требуется, если публичный адрес MCP-сервера не менялся.

## Важные ограничения

**Режим «Полный доступ» остаётся опасным:** разрешённый OAuth-клиент может выполнять произвольные Windows/SSH-команды от текущего пользователя, без подтверждения каждой команды. Это не изоляция средствами Windows. Для недоверенных клиентов используйте «Безопасный» или «Белый список».

**Установщик MCP app пока не подписан Authenticode-сертификатом издателя.** На некоторых компьютерах Windows SmartScreen может выводить предупреждение; контрольные суммы не заменяют цифровую подпись.

Приложение протестировано автоматическими unit/integration-сценариями на Windows и Ubuntu и прошло `--selftest` собранного Windows EXE. Реальный сценарий Cloudflare+Notion/SSH на вашем компьютере рекомендуется проверить после установки.

Подробности: [журнал OAuth, Cloudflare и Windows/SSH](https://github.com/SolasFor/MCP-app/blob/main/docs/oauth-execution-audit.md).
