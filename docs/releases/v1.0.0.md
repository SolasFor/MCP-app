# MCP-app v1.0.0 Release Notes

## Highlights

- **4 UI Transport Providers + Safe Fallback**: Cloudflare Quick (`*.trycloudflare.com`), Cloudflare Named (API Token auto-setup or existing Cloudflare Tunnel Token mode), ngrok Agent v3, and Tailscale Funnel, managed through `ConnectionManager` with per-provider persistence across switches, issuer-change guards, and safe legacy `openai_tunnel` / `local_only` -> `none` migration (internal loopback remains for headless/backend testing only).
- **Full Persistent Logging & Redacted Diagnostics**: Centralized multi-process-safe `%APPDATA%\MCPApp\logs\` (`15` component log files + `.gz` `archive/`, protected audit preservation, Settings UI controls, redesigned Logs tab, and secret-free Diagnostic ZIP export).
- **Proxy System Overhaul & Chromium OAuth Fix**: Proxy defaults to `none` (direct, zero hardcoded `127.0.0.1:1080`), supports `auto` discovery with real protocol/auth/TLS validation (no silent direct fallback) and `manual` (`SOCKS5H`/`SOCKS5`/`HTTP CONNECT` + DPAPI credentials); OAuth `/oauth/consent` fixes Chromium/Edge 303 redirect CSP `form-action` blocking, adds CSRF + friendly HTML error/retry pages, and is verified live in Chromium, Chrome, Edge, and Firefox.
- **Optimized Windows Package**: Kept PyInstaller `onedir` format while trimming `_internal` by `29.43 MB` (`160.37 MB -> 130.94 MB`, `-157` files) and portable ZIP by `11.68 MB` (`67.06 MB -> 55.38 MB`), preserving all runtime metadata and licenses.
- **3 OAuth Execution Scenarios**: `allowlist` (default on first launch, configurable before server start), `safe` (fail-closed fallback), and `full` (arbitrary CMD/PowerShell/SSH without internal per-call prompts; never enabled automatically; explicitly not an OS sandbox), backed by encrypted SQLite (`SCHEMA_VERSION = 3`), live per-client tool propagation (`notifications/tools/list_changed`), owner-token-rotation reconnect preservation, and global Emergency Stop.
- **Unified Tool Ecosystem**:
  - **MCP Gateway**: `stdio`, `Streamable HTTP`, `SSE` upstream aggregation + `solidworks_mcp_template`.
  - **Task Manager**: Persistent async jobs, cancel/restart, bounded output spooling, retention cleanup.
  - **Server Manager**: Local templates, dependency DAGs, readiness probes, SecretStore env injection.
  - **Workspaces & Git**: Guarded file ops, SHA-256 optimistic patches, rollback history, safe Git.
  - **Computer Use**: Opt-in Win32/UIA screen capture & control failing closed on UAC/locked sessions/UIPI.
  - **Extensions**: Out-of-process JSON-RPC SDK, Ed25519/SHA-256 packaging, 4 official extensions.
  - **Remote Management**: Strict `RejectPolicy` `known_hosts`, SSH/SFTP with canonical roots & quotas.
  - **Automation & Monitoring**: TZ/DST scheduler, metrics, loopback-only Admin REST API, live-warned MCP Playground, non-secret backups, staged Ed25519 updater, `--headless` backend mode.
- **Linear + Docker Desktop UI**: Dark/Light/System themes (top-right `SafeComboBox` synced with Settings, cached QSS/PNG/palette switching in <200ms), silent custom dialogs/popups (`SilentDialog`, `SilentMessageBox`, `SilentNotificationPopup`), wheel-safe `SafeComboBox`, live RU/EN i18n, Command Palette (`Ctrl+K`), HiDPI.

## Known Limitations & Honest Release Blockers

1. **Unsigned Windows Binaries (Authenticode Blocker)**: No owner Authenticode `.pfx` certificate is configured locally or in CI. Windows SmartScreen warnings apply on first launch, and `StagedUpdater.auto_install_enabled` remains **`False`** by design.
2. **72-Hour Continuous Soak Test (`NOT_RUN`)**: Automated stress tests cover bounded 21+ MiB output floods, concurrent clients, mid-flight OAuth revocation, and fail-closed broken config recovery; a multi-day continuous 72-hour soak run has not been executed.
3. **External Live Provider / Client Matrix (`BLOCKED`)**: `local_only`, `cloudflared --selftest`, `LocalSSHServer`, `stdio`/`Streamable HTTP`/`SSE` upstreams, and out-of-process extensions were tested live locally. Live external roundtrips requiring owner accounts/licenses (Cloudflare Named domain, ngrok, Tailscale Funnel ACL, ChatGPT/Claude/Gemini/Notion connectors, `SLDWORKS.exe` COM) remain blocked awaiting owner credentials.
4. **Repository Merge & Public Release Gate**: Per `AGENTS.md`, stacked PRs #20–#31 await explicit owner approval before merging into `main` and publishing the official GitHub Release `v1.0.0`.
