# MCP-app v1.0.0 Release Notes

## Highlights

- **6 Tunnel & Connection Modes**: Cloudflare Quick (`*.trycloudflare.com`), Cloudflare Named, ngrok, Tailscale Funnel, OpenAI Secure MCP Tunnel, and Local Only (`127.0.0.1`), managed through `ConnectionManager` with issuer-change warnings and route-ownership guards.
- **3 OAuth Execution Scenarios**: `safe` (default), `allowlist`, and `full` (arbitrary CMD/PowerShell/SSH without internal per-call prompts; never enabled automatically; explicitly not an OS sandbox), backed by encrypted SQLite (`SCHEMA_VERSION = 2`) and global Emergency Stop.
- **Unified Tool Ecosystem**:
  - **MCP Gateway**: `stdio`, `Streamable HTTP`, `SSE` upstream aggregation + `solidworks_mcp_template`.
  - **Task Manager**: Persistent async jobs, cancel/restart, bounded output spooling, retention cleanup.
  - **Server Manager**: Local templates, dependency DAGs, readiness probes, SecretStore env injection.
  - **Workspaces & Git**: Guarded file ops, SHA-256 optimistic patches, rollback history, safe Git.
  - **Computer Use**: Opt-in Win32/UIA screen capture & control failing closed on UAC/locked sessions/UIPI.
  - **Extensions**: Out-of-process JSON-RPC SDK, Ed25519/SHA-256 packaging, 4 official extensions.
  - **Remote Management**: Strict `RejectPolicy` `known_hosts`, SSH/SFTP with canonical roots & quotas.
  - **Automation & Monitoring**: TZ/DST scheduler, metrics, loopback-only Admin REST API, live-warned MCP Playground, non-secret backups, staged Ed25519 updater, `--headless` backend mode.
- **Linear + Docker Desktop UI**: Dark/Light/System themes, live RU/EN i18n, Command Palette (`Ctrl+K`), HiDPI.

## Known Limitations & Honest Release Blockers

1. **Unsigned Windows Binaries (Authenticode Blocker)**: No owner Authenticode `.pfx` certificate is configured locally or in CI. Windows SmartScreen warnings apply on first launch, and `StagedUpdater.auto_install_enabled` remains **`False`** by design.
2. **72-Hour Continuous Soak Test (`NOT_RUN`)**: Automated stress tests cover bounded 21+ MiB output floods, concurrent clients, mid-flight OAuth revocation, and fail-closed broken config recovery; a multi-day continuous 72-hour soak run has not been executed.
3. **External Live Provider / Client Matrix (`BLOCKED`)**: `local_only`, `cloudflared --selftest`, `LocalSSHServer`, `stdio`/`Streamable HTTP`/`SSE` upstreams, and out-of-process extensions were tested live locally. Live external roundtrips requiring owner accounts/licenses (Cloudflare Named domain, ngrok, Tailscale Funnel ACL, OpenAI Secure MCP Tunnel, ChatGPT/Claude/Gemini/Notion connectors, `SLDWORKS.exe` COM) remain blocked awaiting owner credentials.
4. **Repository Merge & Public Release Gate**: Per `AGENTS.md`, stacked PRs #20–#31 await explicit owner approval before merging into `main` and publishing the official GitHub Release `v1.0.0`.
