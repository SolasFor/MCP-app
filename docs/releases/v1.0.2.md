# MCP App v1.0.2 — компактный интерфейс и инструкции

## Что нового

- Подключения: контекстные меню четырёх провайдеров, отдельные инструкции, компактные строки и иконки токена.
- Журналы: поиск, источник, уровень, копирование, очистка, автопрокрутка и счётчики в компактной панели. Экспорт непосредственно из вкладки удалён; обычные файлы журналов и защищённый аудит сохранены.
- Серверы, Workspaces, Задачи, Gateway, Расширения и Устройства: общие панели, регулируемые области списка и деталей; переключаемые вкладки там, где несколько видов деталей.
- Расширения и Устройства: инструкции по назначению, настройке, использованию и безопасности на русском и английском; компактные кнопки.
- Исправлены указатель курсора у кнопки меню провайдера и повтор заголовков при смене языка.

## Установка и обновление

Скачайте Setup или portable ZIP со страницы [Releases](https://github.com/SolasFor/MCP-app/releases). Закройте приложение через трей перед обновлением. Setup устанавливается без администратора. Не удаляйте `%APPDATA%\MCPApp`: там хранятся настройки, секреты и OAuth-клиенты. Новая миграция данных не требуется.

Проверяйте контрольные суммы в SHA256SUMS.txt. Сборка не имеет доверенной подписи издателя, автоматическая установка обновлений отключена. Пакет выпускается через gated Windows workflow после тестов, сборки, selftest, проверок установки, обновления и удаления; SBOM прилагается.

## Ограничения

Расширения не являются OS sandbox; полный доступ выполняет команды с правами пользователя. Для удалённых устройств обязательна проверка ключей SSH. Изменения версии относятся к интерфейсу, не расширяют права клиентов. Ручное визуальное сравнение всех экранов и проверка всех внешних туннелей на реальных аккаунтах не заменяются автоматическими тестами.
