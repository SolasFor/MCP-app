# MCP App v1.1.0 — промежуточный выпуск N01–N05
## Изменения
- N01: исправления стабильности backend, планировщика и задач.
- N02: безопасный staged updater; production auto-install и boot-recovery заблокированы.
- N03: Server Manager внутри Workspaces, единый runtime GUI/MCP, история задач.
- N04: мастер Workspaces, ограниченный статический анализ, контроль манифестов и точный preview.
- N05: SSH-мастер, импорт SSH Config, opt-in discovery, проверка host key до auth, agent/key/password, определение ОС, deny-by-default, атомарный commit и единый legacy trust.
## Установка
После публикации скачайте Setup или portable ZIP из GitHub Releases. Закройте MCP App через трей. Не удаляйте %APPDATA%\MCPApp. Сборка без доверенной подписи издателя: проверяйте происхождение и SHA256SUMS.txt; контрольная сумма не заменяет подпись. Только ручная установка, не включать unsigned auto-install.
