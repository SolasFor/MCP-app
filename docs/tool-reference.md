# MCP-app v1.0.1 Complete Tool Reference

All built-in MCP tools are centrally defined in `backend/tool_registry.py` (`DEFAULT_REGISTRY`) and enforced per-call by `backend/tool_permissions.py` (including dynamic Gateway upstream tools when enabled).

| Category | Tool Name | Min Profile | Notes |
|---|---|---|---|
| **Core** | `server_info` | `safe` | Read-only status reporting effective caller `profile`, `computer_use` (`disabled`/`view`/`control`), and `server_mode`; leaks no secrets or paths. |
| **OAuth Exec** | `oauth_windows_command` | `allowlist` | Allowlist enforces exact commands (built-in safe `dir`/`ls`/`pwd`/`echo` without shell); `full` runs arbitrary shell. |
| **OAuth Exec** | `oauth_ssh_command` | `allowlist` | Allowlist enforces exact host + command; `full` permits arbitrary SSH commands on approved targets. |
| **OAuth Exec** | `oauth_managed_server` | `full` | Direct legacy managed-server lifecycle control. |
| **Tasks** | `task_start`, `task_status`, `task_list`, `task_output`, `task_result`, `task_cancel`, `task_restart`, `task_artifacts` | `allowlist` | Async job execution with profile-aware default timeouts (`15s`/`12s` in `allowlist`, `60s` in `full`), 13 structured `TASK_*` MCP errors, spool ring buffers, disk quotas, idempotency keys, inactive purge, and live OAuth revoke checks. |
| **Servers** | `server_list`, `server_start`, `server_stop`, `server_restart`, `server_status`, `server_logs`, `server_metrics`, `server_health` | `allowlist` | Local service manager with templates (`FastAPI`, `Flask`, `Node`, `Docker`), dependency DAGs, readiness probes, redacted logs, optional `workspace_id` context scoping, and cross-layer workspace authorization. Payloads include `linked_workspaces`. |
| **Workspaces** | `workspace_list`, `workspace_info`, `workspace_tree`, `workspace_read_file`, `workspace_write_file`, `workspace_search`, `workspace_apply_patch`, `workspace_move_file`, `workspace_delete_file`, `workspace_diff`, `workspace_history`, `workspace_run_task` | `allowlist` | Guarded per-project read/write/delete/execute/git permissions, canonical/junction/ADS protections, hash concurrency preconditions, rollback history, `linked_servers_status` / `missing_linked_servers` in `workspace_info`, and `TaskStore` `task_id` tracking in `workspace_run_task`. |
| **Git** | `git_status`, `git_diff`, `git_log`, `git_branches`, `git_checkout`, `git_commit` | `allowlist` | Non-shell Git operations respecting `trust_hooks=False` by default. |
| **Computer Use** | `desktop_screenshot`, `desktop_list_windows`, `desktop_list_monitors`, `desktop_get_ui_tree`, `desktop_wait_for_element` *(view)*; `desktop_open_app`, `desktop_close_window`, `desktop_focus_window`, `desktop_click`, `desktop_type`, `desktop_keypress`, `desktop_scroll`, `desktop_drag` *(control)* | `allowlist` | Dynamically gated by `DesktopPolicy`: hidden when `enabled=False`, split into `allow_screen_capture` (5 view tools) and `allow_input_control` (8 control tools), never exposed in `safe`. UAC/UIPI/locked-desktop fail-closed; screenshots are memory-only `ImageContent`. |
| **Extensions** | `extension_list`, `extension_info`, `extension_call_tool`, `extension_logs` | `allowlist` | Inspect/call approved out-of-process extensions under client & mutating-tool approvals. |
| **Extensions** | `extension_enable`, `extension_disable` | `full` | Enable or disable installed extensions via MCP. |
| **Remote** | `device_list`, `device_info`, `device_health`, `ssh_execute`, `ssh_task_start`, `sftp_list`, `sftp_download`, `sftp_upload`, `remote_service_list`, `remote_service_start`, `remote_service_stop`, `remote_metrics` | `allowlist` | Strict `RejectPolicy` `known_hosts`, canonical SFTP root & symlink guards, scoped command/service allowlists, no auto-`sudo`. |
| **Gateway** | `<upstream>_<tool>` *(dynamic)* | Configured per upstream (`safe`/`allowlist`/`full`) | Proxied upstream MCP tools (`stdio`, `Streamable HTTP`, `SSE`) with loop prevention and secret isolation. |
